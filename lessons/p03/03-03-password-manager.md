For years, Vreni, 81, kept her passwords in a small notebook in the kitchen drawer. It worked, until she couldn’t read her own handwriting, and until she took the notebook on holiday and nearly lost it.

Her son showed her that her iPhone already had a safe “notebook” built in. Now, when she signs in to a website, the phone fills in the password for her. When she makes a new account, it suggests a strong password and remembers it. “It’s like having a very good secretary,” Vreni says.
:::end

:::remember
**A password manager remembers all your passwords, so each one can be long, random and different. You only need to remember one.**
:::end

## What a password manager does

A [[term:password-manager|password manager]] is an app that stores your passwords safely, locked behind your phone’s screen lock, your face or fingerprint, or one main password.

:::figure notebook
A password manager is a locked notebook that fills itself in.
:::end

CISA, the US cyber security agency, describes a password manager as an easy-to-use program that creates, stores and even fills in all your passwords. It also tells you when a password is weak or used more than once. With a password manager, you only need to remember one strong password, the one for the password manager itself ([CISA: Use strong passwords](https://www.cisa.gov/secure-our-world/use-strong-passwords)).

## You probably already have one

CISA notes that some password managers are free, like the ones built into web browsers, and some cost money ([CISA](https://www.cisa.gov/secure-our-world/use-strong-passwords)).

- **iPhone:** from iOS 18, iPhones have an app called **Passwords**. It stores your passwords and warns you about weak, reused or leaked ones ([Apple Support](https://support.apple.com/en-us/120758)).
- **Android:** **Google Password Manager** is built into Chrome and your Google Account. It can save your passwords and suggest strong new ones ([Google Chrome Help](https://support.google.com/chrome/answer/95606?co=GENIE.Platform%3DAndroid&hl=en)).

There are also separate password manager apps from other companies. This course doesn’t recommend a specific product. The built-in option is a good, free start.

## “Is it safe to keep all my passwords in one place?”

It is a fair question. A good password manager keeps your passwords locked, and only you can open it. The bigger risk for most people is using the same weak password everywhere, as lesson 03.01 showed. CISA recommends a password manager instead of writing passwords down ([CISA](https://www.cisa.gov/secure-our-world/use-strong-passwords)).

Protect the password manager itself: use a strong screen lock or main password, and never tell it to anyone who calls you.

## A passphrase for the one you remember

If your password manager asks for one main password, make it a passphrase: several random words. CISA suggests four to seven unrelated words, such as “Horse Purple Hat Run Bay” ([CISA](https://www.cisa.gov/secure-our-world/use-strong-passwords)). Try making a practice one below.

:::practice passphrase

:::helper
Start with the built-in option on their phone, since it needs no new account or payment. Make sure the phone has a screen lock that only your relative knows. Write the main passphrase (if there is one) on paper and keep it in a safe place at home, not in the phone and not in a wallet.
:::end
